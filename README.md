# Wendy Flores — Niagara REALTOR® Demo

Premium responsive React + Vite landing page created as a client demo.

## Included
- Modern editorial real-estate design
- User-supplied Wendy Flores headshot
- Smooth Framer Motion reveal/parallax animations
- Responsive mobile navigation
- Buy / Sell / Rent service cards
- Niagara local-focus section
- English + Español positioning
- Click-to-call phone CTA
- WhatsApp CTA with pre-filled message
- Mobile-friendly responsive layout

## Run
```bash
npm install
npm run dev
```

Then open the local Vite URL shown in the terminal.

## Build
```bash
npm run build
```

### Important
The email CTA is intentionally not connected to a real email address because no email address was supplied. Replace `wendy@example.com` in `src/main.jsx` when the real email is available.
